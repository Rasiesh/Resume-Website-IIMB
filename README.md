# Rasiesh Agarwal — Personal Portfolio

A personal website made with HTML, CSS and a little vanilla JavaScript. No framework or build step is required.

## Open the website

1. Extract this folder.
2. Open `index.html` in a browser.
3. Use the navigation to explore About, Journey, Work and the individual project pages.

## Project files

- `index.html` — homepage
- `about.html` — personal story
- `journey.html` — entrepreneurial timeline
- `work.html` — selected projects
- `community.html` — CDC
- `chapters/` — Ageside.ai, Hoptic's, FlowCom, RoBee's, dental and oral care, and YouTube
- `style.css` — colours, typography, layout, responsive design and animations
- `script.js` — mobile menu, reading progress and scroll reveals
- `assets/` — photographs and favicon

## Editing

Change words in the relevant HTML page. Change the shared palette and design in the `:root` section at the top of `style.css`. Replace photographs in `assets/` and update the matching image path if the filename changes.

Read `CODE_GUIDE.md` for a full explanation of the HTML, CSS, JavaScript, animation and responsive layout.

## Publish with GitHub Pages

Upload the contents of this folder to the root of your repository. Keep `index.html`, `style.css`, `script.js`, `assets/` and `chapters/` in their current structure. Then choose **Settings → Pages → Deploy from a branch → main → /(root)**.
